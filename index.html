Chipin

MVP shipped

Expense splitting with double-entry ledger, analytics, and per-group custom currencies.

Splitwise solves the surface problem; Chipin goes deeper. Every transaction is recorded as a proper double-entry ledger entry — no implicit balances, no drift. Groups can define their own unit of currency (useful for trips, shared houses, or any context where "points" make more sense than rupees). Analytics layer surfaces spending patterns, balance history, and settlement suggestions over time.

  • TypeScript
  • Node.js
  • PostgreSQL
  • Double-entry accounting

Auth Sidecar

shipped

Drop-in authentication service in Go — handles the full token lifecycle for any project.

A self-contained Go service that bundles alongside any application and owns auth end-to-end. Integrates with the main app either via API or direct DB access. Acts as an ingress gate — only authenticated requests are forwarded upstream. Supports HMAC, RSA, EdDSA and the broader JWT signing algorithm surface. The goal: zero auth boilerplate in your main service, ever.

  • Go
  • JWT
  • HMAC
  • RSA
  • EdDSA
  • API gateway

Pixart

wip

Reddit r/place — but infinite horizontal scroll, built specifically to stress-test scale.

Collaborative pixel canvas with no horizontal boundary. The conceit is simple: how far can you push a real-time, multi-user shared canvas before it breaks? Deliberate exercise in the "useless software" genre — the product is almost beside the point; the interesting problems are conflict resolution at write time, efficient viewport rendering of a canvas that has no right edge, and fan-out at high concurrency.

  • WebSockets
  • Canvas API
  • Distributed systems
  • TypeScript

Foundry

shipped

Steam-style time tracker for local codebases — per-language analytics and project history.

Java watchservice daemon that monitors whichever directories you point it at. Tracks active time per project, breaks it down by language, and builds a full timeline of when and how long you worked — exactly like Steam's playtime stats but for your own code. Stores history locally; surfaces it through an analytics dashboard. Built because "how much time have I actually spent on this?" should have a real answer.

  • Java
  • Watchservice API
  • SQLite
  • Analytics

AR Locator

wip

Bluetooth triangulation and AR-guided navigation for GPS-denied environments.

GPS falls apart indoors, underground, and in dense vertical spaces. AR Locator takes over once you're close enough: Bluetooth beacons triangulate the target user's position and guide you toward them. Later-stage work integrates an AR overlay so directions feel spatial, not map-based. Built for the real frustration of trying to find someone in a mall, festival, or multi-floor building.
